# 모바일 앱

React Native와 Expo SDK 58 기반 앱입니다. Expo Router로 화면을 구성하고, 위치 권한은 음식점 주변 검색을 구현할 때 사용합니다.

## 시작

```sh
npm install
npm run start
```

Android 에뮬레이터는 `npm run android`, iOS 시뮬레이터는 `npm run ios`로 실행합니다.

앱은 남위례역과 가락시장역을 직접 선택해 각 3 km 내 식당을 거리순으로 조회합니다. 첫 200곳 이후에는 **더 보기**로 다음 200곳을 불러옵니다. 서버 주소는 `EXPO_PUBLIC_API_BASE_URL`로 지정합니다. iOS 시뮬레이터 기본값은 `http://localhost:8080`이며 Android 에뮬레이터에서는 `http://10.0.2.2:8080`, 실기기에서는 개발 컴퓨터의 LAN 주소를 사용하세요.

상단의 위치를 눌러 두 역을 전환합니다. 하단의 홈·커뮤니티·지도·채팅·마이 탭과 우측 상단의 검색·알림·메뉴 버튼이 있습니다. 검색 버튼은 선택한 역의 3 km 안에서 음식점 이름을 검색하는 화면을 엽니다. 검색 결과도 200개씩 더 볼 수 있습니다. 홈·검색 목록과 지도 마커에서 식당 상세로 이동할 수 있고, 상세에서 최대 8곳을 개인용 돌림판 후보로 담습니다. 돌림판은 홈 버튼이나 메뉴에서 열며 후보 2곳부터 사용할 수 있습니다. 후보는 앱을 종료하면 초기화됩니다. 커뮤니티에서는 간결한 글 목록, 조회수·댓글 수, 글 상세·작성·내 글 수정·삭제, 댓글 조회·작성·내 댓글 삭제와 같이 먹기 모집·참여를 사용할 수 있습니다. 채팅 탭에서는 참여 중인 모집을 열어 대화할 수 있으며 채팅방은 5초 간격으로 새 메시지를 가져옵니다. 알림은 준비 중 화면입니다.

지도는 Expo SDK 58의 `react-native-maps`를 사용합니다. Expo Go에서는 별도 키 없이 테스트할 수 있지만, Android 앱 바이너리를 배포할 때는 [Expo 지도 설정 안내](https://docs.expo.dev/versions/v58.0.0/sdk/map-view/)에 따라 Google Maps API 키를 앱 빌드 설정에 추가해야 합니다. 키를 저장소에 넣지 마세요.

개발 환경에는 Node.js 22.13 이상과 Android Studio 또는 Xcode가 필요합니다. Expo SDK 패키지 버전은 SDK 58 권장 버전에 맞춰 관리합니다.
