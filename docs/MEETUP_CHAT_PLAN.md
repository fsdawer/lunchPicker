# 같이 먹기 모집과 채팅 구현 계획

- 지역 사용자에게 3 km 안의 모집을 보여준다. 회사 소속은 요구하지 않는다.
- 로그인 사용자는 음식점·시작 시간·정원으로 모집을 만들고, 호스트는 자동 참여한다.
- 참여·취소는 서버에서 작성자/참여자와 정원을 검증한다. 모집 행 잠금으로 마지막 자리의 동시 신청을 직렬화한다.
- 채팅은 모집 참여자만 읽고 쓸 수 있다. 메시지는 DB에 저장하고 앱이 열린 동안 주기적으로 새 메시지를 조회한다.
- 순서: 커뮤니티 수정 검증 → 모집 DB/API/테스트 → 모집 화면 → 채팅 DB/API/테스트 → 채팅 화면 → 전체 검증.
